| 状態 | 意味 |
|---|---|
| 未着手 | テストをまだ書いていない |
| 未達 | テストを書いたが、まだ通らない (`#[ignore = "expected-fail: <ID>"]` を付けて置く。gate の期待失敗の照合の対象) |

### 確かめ方

| 確かめ方 | 中身 |
|---|---|
| Driver の受け入れテスト | ユーザーの操作の語彙だけを使う Driver を通して書くテスト。パネルの操作も Driver から行う |
| proptest | 任意の入力の列で性質が成り立つことを確かめるテスト |
| 障害注入 | 書込みの失敗やプロセスの強制終了を起こして確かめるテスト |
| perf の計測 | 計測ハーネスか perf ジョブで測る |
| オーナーの実機デモ | オーナーが自分の環境で操作して確かめ、DEMO-LOG に記録する (Phase 1 のスパイクの結果は、ADR 020 の付録 H に記録する) |
| CI の検査 | CI が合否を判定する |
| オーナーの確認 | オーナーが文書・設定・記録を見て確かめる |
